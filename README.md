# しりとりアプリ

## デプロイ先

https://shiritori.yoshiha3.deno.net/

## 実装した機能

課題で必須とされていた以下の機能を実装しました。

- 直前の単語を表示する
- 任意の単語を入力できる
- 直前の単語の末尾と入力した単語の先頭を比較し、一致した場合のみ単語を更新する。一致しない場合はエラーメッセージを表示する
- 「ん」で終わる単語が入力されたらゲームを終了する
- 過去に使用した単語が入力されたらゲームを終了する
- ゲーム中・ゲーム終了後のどちらでも最初からやり直せるリセット機能

加えて、以下の機能を実装しました。

- 入力できる文字をひらがなと「ー」のみに制限
- ゲーム終了時に終了理由を表示
- 長音符号や小さい文字で単語が終わる場合を適切に判定
  - 小さい文字（ゃ・ゅ・ょ・ぁなど）で終わる場合は対応する大きい文字として扱う（例：**まっちゃ
    → やたい**）
  - 長音符号（ー）で終わる場合は、一つ前の文字の母音を次の文字として扱う（例：**こーひー
    → いす**）
- Enterキーで単語を送信できるように対応

## デザイン

画面中央にゲーム画面を配置したシンプルなUIを実装しました。

デザインについては最低限使いやすいものを目指しましたが、今後さらに改善していきたいと考えています。

## 工夫したこと

コードの可読性を保ち、機能の追加や修正をしやすくすることを意識して実装しました。

特に、役割ごとに処理を分割することを意識しました。例えば、

- サーバーとの通信
- しりとりのゲームロジック
- 文字変換処理
- UI更新

といったように、責務ごとに処理を分けています。

また、共通して使用する処理は関数としてまとめることで、同じコードを何度も書かずに済むようにし、保守性や再利用性を高めました。
